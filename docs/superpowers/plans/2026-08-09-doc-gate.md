# Doc Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gate the documents the doc-generator produces so contradictions and unsound designs are caught before the planner derives tasks from them, instead of after the objective ships.

**Architecture:** Two enforcement points share one content-keyed attestation. A `PreToolUse` matcher on the `Agent` tool blocks a `nazgul:planner` dispatch until the current doc set carries an attestation; a demoted branch in `stop-hook.sh` is the bounded backstop. Findings arrive on two channels — a script-written sidecar from the doc-generator and a `doc-reviewer` verdict — and route by two orthogonal axes: `verifiability` governs a bounded retry loop, `class` governs the terminal disposition.

**Tech Stack:** Bash (POSIX-safe), `jq`, `git`, Claude Code hooks (`PreToolUse`, `Stop`), the Nazgul agent/skill markdown format.

**Spec:** `docs/superpowers/specs/2026-08-09-doc-gate-design.md` (commit `911603c`). Read it before Task 1 — every design decision below is justified there and is not re-argued here.

## Global Constraints

- Shell scripts use `set -euo pipefail`. Two documented exceptions omit `-e`: sourced libs under `scripts/lib/` (must not alter the caller's shell options) and fail-open observe-only hooks. Test files under `tests/` use `set -uo pipefail` so they can assert on nonzero exits.
- Quote all variables. Use `jq` for JSON, never `sed`/`grep`.
- All scripts must pass `bash -n` and `shellcheck`. `tests/test-shellcheck.sh` scans the whole tree.
- File naming: kebab-case. The default branch is always `main`, never `master`.
- Comments stay lean: no run of more than 2 comment lines; relocate rationale to the spec or `RULES.md` rather than inlining it.
- Every enumerated field is a **closed** set. An unrecognized token is rejected by name, never pattern-matched. Precedent: `scripts/lib/task-transition-guard.sh:129-131`.
- Config reads use `if .x == false then "false" else "true" end`, never `// true` — the latter false-coalesces an explicit `false` back on (`scripts/stop-hook.sh:258-260`).
- Every task in this plan touches `scripts/**` or `tests/**`, so `guards.red_run_evidence` requires real red-run evidence at IMPLEMENTED. **No enumerated exemption applies to any task here** — the closed list is `docs-only comment-only revert fixture-capture-only` and none fits.
- The retry ladder `nazgul/logs/.doc-gate-attempts` is **objective-keyed** (`feat_id`). The attestation `nazgul/docs/.review/<docs-hash>.json` is **content-keyed**. These must never share a key.
- Work happens in the worktree at `.claude/worktrees/doc-gate-design` on branch `worktree-doc-gate-design`. Baseline at start: `99 files checked, 99 passed, 0 failed`.

```bash
#!/usr/bin/env bash
# Doc-gate shared library. Sole computer of docs_hash and sole home of the
# classification procedure (spec: docs/superpowers/specs/2026-08-09-doc-gate-design.md).
# No `set -e`: a sourced lib must not alter the caller's shell options.
set -uo pipefail

[ -n "${_DOC_GATE_SOURCED:-}" ] && return 0
_DOC_GATE_SOURCED=1

_dg_sha256() {
  if command -v sha256sum >/dev/null 2>&1; then
    sha256sum | awk '{print $1}'
  elif command -v shasum >/dev/null 2>&1; then
    shasum -a 256 | awk '{print $1}'
  else
    return 1
  fi
}

# Excludes manifest.md: it is bookkeeping about the documents, not a document
# that makes claims, and its Approved column churns without any claim changing.
doc_set_hash() {
  local docs_dir="${1:-}"
  [ -n "$docs_dir" ] && [ -d "$docs_dir" ] || return 1

  local stream="" f rel h
  while IFS= read -r f; do
    rel="${f##*/}"
    [ "$rel" = "manifest.md" ] && continue
    h="$(_dg_sha256 < "$f")" || return 1
    stream="${stream}${h}  ${rel}"$'\n'
  done < <(find "$docs_dir" -maxdepth 1 -type f -name '*.md' -print | LC_ALL=C sort)

  printf '%s' "$stream" | _dg_sha256 | cut -c1-16
}
```

```bash
# Closed registry, mirrored from RULES.md §21. Enumerate-the-allowed-set: an
# open-ended invariant field would be an allow-everything field.
_DG_INVARIANTS="INV-STATE INV-WRITER INV-BOARD INV-SCOPE INV-RECOVERY INV-COVERAGE INV-DISPATCH INV-DELIVERY INV-ROOT INV-FAILCLOSED INV-SECRET"

dg_invariant_known() {
  case " $_DG_INVARIANTS " in
    *" ${1:-} "*) return 0 ;;
    *) return 1 ;;
  esac
}

dg_classify() {
  local class="${1:-}" ref="${2:-}" t2="${3:-unknown}" t3="${4:-unknown}"

  if [ "$class" = "security" ]; then
    printf 'architecture-invariant'; return 0
  fi
  if ! dg_invariant_known "$ref"; then
    printf 'ordinary'; return 0
  fi
  if [ "$t2" = "yes" ] || [ "$t3" = "no" ]; then
    printf 'architecture-invariant'; return 0
  fi
  if [ "$t2" = "unknown" ] || [ "$t3" = "unknown" ]; then
    printf 'architecture-invariant'; return 0
  fi
  printf 'ordinary'
}

dg_route() {
  local v="${1:-}" class="${2:-}" n="${3:-0}" max="${4:-3}"
  case "$n" in ''|*[!0-9]*) n=0 ;; esac
  case "$max" in ''|*[!0-9]*) max=3 ;; esac

  if [ "$v" = "mechanical" ] && [ "$n" -lt "$max" ]; then
    printf 'retry_filed'; return 0
  fi
  case "$class" in
    architecture-invariant|security) printf 'blocked' ;;
    *) printf 'dissent_recorded' ;;
  esac
}
```

```bash
dg_sidecar_path() {
  local docs_dir="$1" h
  h="$(doc_set_hash "$docs_dir")" || return 1
  printf '%s/.review/%s.contradictions.json' "$docs_dir" "$h"
}

dg_sidecar_state() {
  local docs_dir="${1:-}" p
  p="$(dg_sidecar_path "$docs_dir")" || { printf 'generator_channel_corrupt'; return 0; }
  [ -f "$p" ] || { printf 'generator_channel_unrun'; return 0; }

  local n
  n="$(jq -r 'if (.sv==1 and (.docs_hash|type=="string") and (.findings|type=="array")
               and (.scanned == (.skipped + .checked))) then (.findings|length) else "bad" end' \
        "$p" 2>/dev/null)" || { printf 'generator_channel_corrupt'; return 0; }
  case "$n" in
    ''|bad) printf 'generator_channel_corrupt' ;;
    0)      printf 'looked_found_none' ;;
    *)      printf 'has_findings' ;;
  esac
}
```

- [ ] **Step 4: Write the emitter**

Create `scripts/doc-gate.sh`. The agent never authors JSON — every field is built with `jq --arg`, the `raise_finding()` posture (`scripts/lib/raise-finding.sh:40-101`):

```bash
#!/usr/bin/env bash
# Doc-gate producer. The doc-generator calls this; it never writes JSON itself.
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
# shellcheck source=scripts/lib/doc-gate.sh
. "$SCRIPT_DIR/lib/doc-gate.sh"

CMD="${1:-}"; shift || true
DOCS_DIR=""; FEAT_ID=""; DOC=""; CLAIM=""; LOCATOR=""; CLASS=""; REF=""
VERIF=""; EXPECTED=""; OBSERVED=""; EVIDENCE=""; PROBE=""; SEVERITY=""
CONFIDENCE=""; SCANNED=0; SKIPPED=0; SKIP_REASONS="{}"

for arg in "$@"; do
  case "$arg" in
    --docs-dir=*)      DOCS_DIR="${arg#*=}" ;;
    --feat-id=*)       FEAT_ID="${arg#*=}" ;;
    --doc=*)           DOC="${arg#*=}" ;;
    --claim=*)         CLAIM="${arg#*=}" ;;
    --claim-locator=*) LOCATOR="${arg#*=}" ;;
    --class=*)         CLASS="${arg#*=}" ;;
    --invariant-ref=*) REF="${arg#*=}" ;;
    --verifiability=*) VERIF="${arg#*=}" ;;
    --expected=*)      EXPECTED="${arg#*=}" ;;
    --observed=*)      OBSERVED="${arg#*=}" ;;
    --evidence=*)      EVIDENCE="${arg#*=}" ;;
    --probe=*)         PROBE="${arg#*=}" ;;
    --severity=*)      SEVERITY="${arg#*=}" ;;
    --confidence=*)    CONFIDENCE="${arg#*=}" ;;
    --scanned=*)       SCANNED="${arg#*=}" ;;
    --skipped=*)       SKIPPED="${arg#*=}" ;;
    --skip-reasons=*)  SKIP_REASONS="${arg#*=}" ;;
    *) echo "doc-gate: unknown argument: $arg" >&2; exit 1 ;;
  esac
done

[ -n "$DOCS_DIR" ] && [ -d "$DOCS_DIR" ] || { echo "doc-gate: --docs-dir must be a directory" >&2; exit 1; }
HASH="$(doc_set_hash "$DOCS_DIR")" || { echo "doc-gate: cannot compute docs_hash" >&2; exit 1; }
SIDECAR="$DOCS_DIR/.review/${HASH}.contradictions.json"
mkdir -p "$DOCS_DIR/.review"

_dg_reject() { echo "doc-gate: unenumerated token: $1=$2" >&2; exit 1; }

_dg_seed() {
  [ -f "$SIDECAR" ] && return 0
  jq -n --arg h "$HASH" --arg f "$FEAT_ID" \
        --arg t "$(date -u +"%Y-%m-%dT%H:%M:%SZ")" \
    '{sv:1, docs_hash:$h, feat_id:$f, generator:"doc-generator", generated_at:$t,
      scanned:0, skipped:0, checked:0, findings_count:0, skip_reasons:{}, findings:[]}' \
    > "$SIDECAR"
}

case "$CMD" in
  emit)
    case "$CLASS" in architecture-invariant|security|ordinary) ;; *) _dg_reject class "$CLASS" ;; esac
    case "$VERIF" in mechanical|judgment) ;; *) _dg_reject verifiability "$VERIF" ;; esac
    case "$SEVERITY" in HIGH|MEDIUM|LOW) ;; *) _dg_reject severity "$SEVERITY" ;; esac
    case "$CONFIDENCE" in ''|*[!0-9]*) _dg_reject confidence "$CONFIDENCE" ;; esac
    if [ "$CLASS" = "architecture-invariant" ] && ! dg_invariant_known "$REF"; then
      _dg_reject invariant_ref "$REF"
    fi
    if [ "$VERIF" = "mechanical" ]; then
      [ -n "$EXPECTED" ] && [ -n "$OBSERVED" ] && [ -n "$EVIDENCE" ] \
        || { echo "doc-gate: a mechanical finding requires expected, observed, evidence" >&2; exit 1; }
    fi

    _dg_seed
    IDX="$(jq -r '.findings | length + 1' "$SIDECAR")"
    ID="$(printf 'DG-%s-%03d' "$HASH" "$IDX")"
    TMPF="$(mktemp)"
    jq --arg id "$ID" --arg doc "$DOC" --arg claim "$CLAIM" --arg loc "$LOCATOR" \
       --arg class "$CLASS" --arg ref "$REF" --arg v "$VERIF" \
       --arg exp "$EXPECTED" --arg obs "$OBSERVED" --arg ev "$EVIDENCE" \
       --arg probe "$PROBE" --arg sev "$SEVERITY" --argjson conf "$CONFIDENCE" \
      '.findings += [{
         id:$id, doc:$doc, claim:$claim, claim_locator:$loc, class:$class,
         invariant_ref: (if $ref == "" then null else $ref end),
         verifiability:$v,
         expected: (if $exp == "" then null else $exp end),
         observed: (if $obs == "" then null else $obs end),
         evidence: (if $ev == "" then [] else ($ev | split(",")) end),
         probe: (if $probe == "" then null else $probe end),
         severity:$sev, confidence:$conf, disposition:"open", retry_count:0
       }] | .findings_count = (.findings | length)' "$SIDECAR" > "$TMPF"
    mv "$TMPF" "$SIDECAR"
    ;;
  seal)
    _dg_seed
    CHECKED=$((SCANNED - SKIPPED))
    [ "$CHECKED" -ge 0 ] || { echo "doc-gate: scanned must be >= skipped" >&2; exit 1; }
    TMPF="$(mktemp)"
    jq --argjson sc "$SCANNED" --argjson sk "$SKIPPED" --argjson ck "$CHECKED" \
       --argjson sr "$SKIP_REASONS" \
      '.scanned=$sc | .skipped=$sk | .checked=$ck | .skip_reasons=$sr
       | .findings_count = (.findings | length)' "$SIDECAR" > "$TMPF"
    mv "$TMPF" "$SIDECAR"
    ;;
  report)
    dg_sidecar_state "$DOCS_DIR"; printf '\n'
    ;;
  *) echo "doc-gate: usage: doc-gate.sh emit|seal|report ..." >&2; exit 1 ;;
esac
```

```bash
#!/usr/bin/env bash
# PreToolUse(Agent): block a nazgul:planner dispatch until the current doc set
# carries a doc-gate attestation. Planner-scoped; every other dispatch passes.
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
# shellcheck source=scripts/lib/nazgul-root.sh
. "$SCRIPT_DIR/lib/nazgul-root.sh"
# shellcheck source=scripts/lib/doc-gate.sh
. "$SCRIPT_DIR/lib/doc-gate.sh"

INPUT="$(cat)"
SUBAGENT="$(printf '%s' "$INPUT" | jq -r '.tool_input.subagent_type // empty' 2>/dev/null || echo "")"
case "$SUBAGENT" in *planner) ;; *) exit 0 ;; esac

PROJECT_ROOT="$(resolve_project_root)"
NAZGUL_DIR="$PROJECT_ROOT/nazgul"
CONFIG="$NAZGUL_DIR/config.json"
[ -f "$CONFIG" ] && [ -r "$CONFIG" ] || exit 0

ENABLED="$(jq -r 'if .doc_gate.enabled == false then "false" else "true" end' "$CONFIG" 2>/dev/null || echo "true")"
[ "$ENABLED" = "true" ] || exit 0

DOCS_DIR="$NAZGUL_DIR/docs"
[ -d "$DOCS_DIR" ] || exit 0
find "$DOCS_DIR" -maxdepth 1 -type f -name '*.md' -print -quit 2>/dev/null | grep -q . || exit 0

KILL="$(jq -r 'if .guards.doc_gate == false then "false" else "true" end' "$CONFIG" 2>/dev/null || echo "true")"

HASH="$(doc_set_hash "$DOCS_DIR" 2>/dev/null || echo "")"
STATE="$(dg_sidecar_state "$DOCS_DIR")"
ATTEST="$DOCS_DIR/.review/${HASH}.json"

REASON=""
if [ -z "$HASH" ]; then
  REASON="docs_hash could not be computed for the current doc set"
elif [ "$STATE" = "generator_channel_corrupt" ]; then
  REASON="the contradiction sidecar is present but corrupt (generator_channel_corrupt)"
elif [ -f "$ATTEST" ]; then
  OPEN="$(jq -r '[.findings[]? | select(.disposition=="open" or .disposition=="blocked")
                  | select(.class=="architecture-invariant" or .class=="security")] | length' \
          "$DOCS_DIR/.review/${HASH}.contradictions.json" 2>/dev/null || echo 0)"
  [ "$OPEN" = "0" ] || REASON="${OPEN} unresolved architecture-invariant or security finding(s)"
elif [ "$STATE" = "looked_found_none" ]; then
  echo "doc-gate: no doc-reviewer attestation; proceeding on the generator channel alone (degraded_no_reviewer)" >&2
else
  REASON="no doc-gate attestation for the current doc set (${STATE})"
fi

[ -n "$REASON" ] || exit 0

if [ "$KILL" = "false" ]; then
  echo "doc-gate: would block (${REASON}) — suppressed by guards.doc_gate=false" >&2
  exit 0
fi

cat >&2 <<MSG
NAZGUL DOC GATE: BLOCKED — planner dispatch refused.
Reason: ${REASON}
The plan would be derived from documents that have not passed the doc gate.
Run the doc-reviewer over nazgul/docs/, resolve findings, and retry.
Suppress the block only with guards.doc_gate=false in nazgul/config.json.
MSG
exit 2
```

- [ ] **Step 3: Write the drift predicate**

Append to `scripts/lib/doc-gate.sh`. Drift is measured against the merge-base with the base branch — never raw HEAD movement, which would fire on the objective's own commits:

```bash
dg_doc_drift() {
  local doc="${1:-}" root="${2:-}" base="${3:-main}"
  [ -f "$doc" ] || { printf 'corrupt'; return 0; }

  local sha scope
  sha="$(awk '/^## Provenance/{p=1} p && /Base SHA:/{print $NF; exit}' "$doc")"
  scope="$(awk '/^## Provenance/{p=1} p && /Scope:/{sub(/^.*Scope:[[:space:]]*/,""); print; exit}' "$doc")"
  [ -n "$sha" ] && [ -n "$scope" ] || { printf 'stale'; return 0; }

  git -C "$root" cat-file -e "${sha}^{commit}" 2>/dev/null || { printf 'corrupt'; return 0; }

  local mb
  mb="$(git -C "$root" merge-base "$sha" "$base" 2>/dev/null)" || { printf 'corrupt'; return 0; }

  local hit
  hit="$(git -C "$root" diff --name-only "$mb" "$base" -- $scope 2>/dev/null | head -n1)"
  [ -n "$hit" ] && printf 'stale' || printf 'fresh'
}
```
